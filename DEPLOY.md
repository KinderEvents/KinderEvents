## 🚀 Pour Déployer sur Vercel

### Option 1 : Via GitHub (Recommandé)

```bash
# 1. Créer un repo sur GitHub
# Allez sur github.com et créez un nouveau repository

# 2. Lier le repo local
git remote add origin https://github.com/VOTRE_USERNAME/VOTRE_REPO.git

# 3. Pusher le code
git branch -M main
git push -u origin main
```

Vercel détectera automatiquement le push et déploiera ! 🎉

### Option 2 : Via Vercel CLI

```bash
# Installer Vercel CLI
npm i -g vercel

# Déployer
vercel --prod
```

### Option 3 : Via Dashboard Vercel

1. Allez sur [vercel.com/dashboard](https://vercel.com/dashboard)
2. Cliquez sur "Import Project"
3. Sélectionnez le dossier `/Users/mac/Downloads/ai agency`
4. Cliquez sur "Deploy"
