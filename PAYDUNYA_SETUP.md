# Configuration PayDunya

## 🎯 Endpoint IPN Configuré
```
https://visionr-studio.vercel.app/api/payment/confirm
```

## 📋 Table Supabase Requise

Créez cette table dans Supabase pour stocker les paiements :

```sql
create table payments (
  id bigint generated by default as identity primary key,
  transaction_id text unique not null,
  status text not null, -- completed, pending, failed
  amount decimal(10,2),
  currency text default 'XOF',
  customer_name text,
  customer_email text,
  customer_phone text,
  payment_method text,
  receipt_url text,
  custom_data jsonb,
  confirmed_at timestamp with time zone,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Index pour recherche rapide
create index idx_payments_transaction on payments(transaction_id);
create index idx_payments_email on payments(customer_email);
create index idx_payments_status on payments(status);
```

## 🔧 Configuration dans PayDunya

1. **Connectez-vous** à votre compte PayDunya
2. Allez dans **Paramètres** → **API & Webhooks**
3. Dans **IPN URL**, collez :
   ```
   https://visionr-studio.vercel.app/api/payment/confirm
   ```
4. **Sauvegardez**

## 📊 Flux de Paiement

### 1. Client initie le paiement
```javascript
// Dans votre frontend (à créer)
const response = await fetch('/api/payment/initiate', {
    method: 'POST',
    body: JSON.stringify({
        amount: 10000,
        customer_email: 'client@example.com',
        pack: 'Formation Avancée',
        type: 'formation'
    })
});
```

### 2. PayDunya traite le paiement
- Client est redirigé vers PayDunya
- Client paie via Mobile Money / Carte
- PayDunya confirme le paiement

### 3. PayDunya notifie votre serveur
- PayDunya appelle automatiquement `/api/payment/confirm`
- Votre serveur enregistre le paiement dans Supabase
- Votre serveur met à jour le statut de l'inscription

### 4. Confirmation client
- Client reçoit un email de confirmation
- Accès à la formation débloqué

## 🔐 Sécurité (Recommandé)

Pour plus de sécurité, vérifiez la signature PayDunya :

```javascript
// Dans api/payment/confirm.js
const crypto = require('crypto');

function verifyPayDunyaSignature(data, signature, secret) {
    const hash = crypto
        .createHmac('sha256', secret)
        .update(JSON.stringify(data))
        .digest('hex');
    return hash === signature;
}

// Dans le handler
const signature = req.headers['x-paydunya-signature'];
if (!verifyPayDunyaSignature(req.body, signature, 'VOTRE_SECRET')) {
    return res.status(401).json({ error: 'Invalid signature' });
}
```

## 🆘 Dépannage

### L'IPN ne fonctionne pas ?
1. ✅ Vérifiez que l'URL est bien `https://` (pas `http://`)
2. ✅ Vérifiez que le site est déployé sur Vercel
3. ✅ Testez l'endpoint manuellement :
   ```bash
   curl -X POST https://visionr-studio.vercel.app/api/payment/confirm \
     -H "Content-Type: application/json" \
     -d '{"transaction_id":"test123","status":"completed"}'
   ```
4. ✅ Vérifiez les logs Vercel

### PayDunya dit "URL invalide" ?
- L'URL doit être accessible publiquement
- Pas de localhost ou IP privée
- HTTPS obligatoire
